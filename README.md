# P6-Peter-Leap-Ch5

Peter · Reading & Writing Chapter 5. A tap-friendly practice game for Primary 6 English.

Theme: **Books we love.** Motto: **What kind of books do you love?**

Vocabulary and grammar questions are Traditional Chinese. Vocabulary answers stay a picture plus the English word. The pictures are cropped from book page 55. Carrie’s book report, the fiction guide, and the Rainbow Books catalogue stay in English. Buttons, help, and feedback are Traditional Chinese.

This chapter’s writing task is a **book report**. The unit film review belongs on the separate Chapter 6 site, not here.

## Play online

GitHub Pages is not turned on for this repository. That is on purpose. This project does not turn Pages on, and it does not change repository settings.

When Pages is turned on later, use branch `main` and folder `/` (root). The address would be:

https://tradingservant.github.io/P6-Peter-Leap-Ch5/

Paths are relative, so the site can live in that project folder. `css/styles.css` is linked with a relative path. `.nojekyll` is included so Pages will not run Jekyll.

## Open locally

From this folder:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

You can also open `index.html` directly. The game does not need a server. Stars and scores stay in memory only. Reload or close the page and they are gone. There is no login, no database, and no upload of pupil work.

On an iPhone, use Safari. Buttons are large. Add it to the Home Screen if you want an app icon.

Check the answer key without a browser:

```bash
node tests/answers.test.js
```

Teacher samples stay hidden until a student submits, or until **教師模式** is on. Every sample is marked 範例／教師用.

## What is inside

1. **詞彙 Vocabulary** — eight character adjectives from the book pictures: greedy, cruel, proud, selfish, dishonest, wicked, fierce, timid.
2. **文法 Grammar** — who, which, and If I were …, I would … . who and which are not question words here. The books-we-recommend cloze and Maggie’s Alice summary are included.
3. **閱讀 Report** — Carrie Law’s book report on *Charlie and the Chocolate Factory*. Page 54 phonics is a visual -ture / -sure sort. There is no listening task.
4. **閱讀 Book** — five kinds of fiction, then the Rainbow Books Catalogue 2018.
5. **寫作 Book report** — the same report shape as Carrie’s, then one short report. The model answer unlocks after submit.

There is no audio. The page 59 listening cloze is not in this site.

## Answer key

Correct answers follow the Chapter 5 spec. Model writing is marked 範例／教師用 inside the writing steps.

- Picture match is A greedy through H timid.
- who adds information about a person. which adds information about a thing. Imaginary sentences use If I were …, I would … .
- Report cloze: poor, lucky, naughty, good. Naughty follows the approved spec for blank (c).
- Who said it: Violet, Veruca, Mike, Augustus, Charlie.
- Carrie did not write what she does not like about the book.
- Catalogue: others’ comments are the missing information. Treasure Island has a free activity book. Aesop’s Fables is a hardcover. Journey to the West won the Bookworm Award 2015. The Little Mermaid is the cheapest. Age 10+ books are Around the World in 80 Days and Treasure Island. The Grimm pack has three fairy tales.
- The book report order is title and author, main characters, plot, favourite part or character, a character I would like to be, lessons learnt.

Chapter 3 targets (since / too / not enough) and Chapter 4 targets (neither…nor / either…or / shall we) are not new aims. They may appear only as wrong options.
